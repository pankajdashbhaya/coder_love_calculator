# 💖 Coder's Love & Compatibility Calculator (Rust Edition) 🦀

Ek chota, funny aur cute Rust CLI project jo Rust ke **Borrow Checker**, **Lifetimes**, aur **Multi-threading** principles ke hisaab se do logo (ya developer + unki pasandida programming language) ki compatibility calculate karta hai!

---

## 🚀 Kaise Run Karein:

Terminal open karein aur project directory mein jaakar run karein:

```bash
cd /home/pankaj/coder_love_calculator
cargo run
```
